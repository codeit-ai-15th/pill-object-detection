# YOLO26s 2차 실험 (외부 데이터 추가)

- 담당: 이채영
- 노트북: [`yolo26-exp2.ipynb`](yolo26-exp2.ipynb)
- 결과 파일: 드라이브 `pill data/runs/` (run 폴더별 `scores.json`, `val_predictions.json`), `exp2_summary.json`, `exp2_val_gt.json`, `figures/`, `submissions/`

## 목적

AI Hub 데이터로 test에만 있던 약 18종을 train에 넣고, 클래스 불균형도 줄이는 것.

## 데이터와 설정

| 방법 | 고르는 방식 | 클래스 | train 사진 | 배치/에폭 |
| --- | --- | --- | --- | --- |
| v2 | 약마다 목표 200개를 최대한 채우도록 사진 선택 | 118 | 7,129 | 446 |
| v3 | 대회 약이 하나라도 있는 사진 선택 | 96 | 8,974 | 561 |
| v4 | 전체 사진, 대회 밖 약은 others로 묶음 | 75 | 11,206 | 701 |

- val은 공통 1,000장 (1차 val 47장 + AI Hub). 대회 74클래스가 모두 들어 있고, 약 조합 기준 누수 0장
- 모델·설정은 1차 그대로: yolo26s, imgsz 640, batch 16, seed 0, patience 30
- optimizer는 1차에서 auto가 고른 값을 직접 지정: AdamW, lr0 0.000167, momentum 0.9, warmup_bias_lr 0
- 에폭 5 / 10 / 20: 1차 최적 50에폭이 600배치인데 2차는 1에폭이 446~701배치라, 짧은 쪽부터 골랐다
- 환경: e5·e10은 Colab T4 (workers 2), e20은 Colab Pro A100 (workers 8)
- ultralytics 기본값상 마지막 10에폭은 모자이크가 꺼진다. e5·e10은 처음부터 꺼진 채, e20만 앞 10에폭 켜짐

| v2 e10 | 0.9878 | 0.9957 | 0.6019 |
| v2 e20 | 0.9897 | 0.9936 | 제출 안 함 |
| v3 e5 | 0.9846 | 0.9944 | 0.6133 |
| v3 e10 | 0.9901 | 0.9920 | 0.6035 |
| v3 e20 | 0.9918 | 0.9905 | **0.6339** |
| v4 e5 | 0.9838 | 0.9906 | 제출 안 함 |
| v4 e10 | 0.9889 | 0.9922 | 0.6007 |

- 1차 기준 run은 같은 지표로 Kaggle 47장 0.9615, Kaggle public 0.410
- 같은 47장에서는 +0.03~0.04, Kaggle public은 +0.18~0.22

## 분석

- **방법·에폭**: e10끼리 방법 차이 최대 0.003, e5와 e10 차이는 v2·v3에서 방향이 반대. 모두 흔들림 안. v3 e20만 e10보다 +0.030으로 흔들림을 넘었지만 모자이크·GPU·workers가 같이 달라서 에폭만의 효과라고 볼 수 없다
- **val로 run을 못 고른다**: val 순서와 Kaggle 순서가 맞지 않는다
- **클래스 불균형**: train 최소/최대가 v2 27/1,035(38.3배), v3·v4 27/1,263(46.8배). 1차(42.7배)와 비율은 그대로. 클래스별 AP와 train 수의 상관은 0.08로 거의 없다
- **클래스별 AP (9개 run 평균)**: 0.99 이상 51개, 0.95~0.99 19개, 0.95 미만 4개(넥시움, 뮤테란, 리리카, 삐콤씨에프)
- **confusion matrix (v3 e20, 직접 셈)**: 3,053개 중 3,052개 맞춤, 클래스 혼동 0, 못 찾음 1
- **IoU 기준별 AP (v3 e20)**: 0.75 1.0000 / 0.80 1.0000 / 0.85 0.9993 / 0.90 0.9979 / 0.95 0.9617. AP95가 많이 떨어지는 10개 클래스는 train 189~417개로 고르게 퍼져 있고 빈도와의 상관 0.007
- **test 예측 (e5·e10 제출 5개 run)**: 842장 전부 박스 3·4개. 약별 개수가 팀 test 검수표와 3,229개 중 3~6개 차이. 1차의 희귀 약 과잉 예측은 사라짐

## 결론

- 외부 데이터 효과는 확실하다. Kaggle 최고 0.410 → 0.634 (+0.22)
- 데이터 고르는 방법(v2·v3·v4)끼리는 우열이 없다
- val은 0.98~0.99로 포화돼서 Kaggle을 대표하지 못한다. 남은 val–Kaggle 차이는 원인을 특정하지 못했다

| 원인 후보 | 판정 | 근거 |
| --- | --- | --- |
| test 전용 약 | 해소 | test 약별 개수가 검수표와 거의 같음 |
| 클래스 혼동 | 아님 | val 혼동 0, test 약별 개수 일치 |
| 놓치거나 더 찍음 | 아님 | test 사진당 박스 3·4개, 검수표와 일치 |
| test 박스가 덜 정밀함 | 확인 못 함 | test 정답 없음. val은 IoU 0.90까지 거의 만점 |
| 점수 낮은 박스가 손해 | 근거 약함 | 0.5 미만 박스 run당 최대 6%. 가장 많은 v3 e5가 e5·e10 중 최고점 |

## 한계

- 모든 run을 seed 0 한 번씩만 돌렸다
- e20 Kaggle은 v3만 냈고, 에폭과 모자이크·GPU·workers가 같이 바뀌었다
- test 검수표는 사람이 확인한 추정치
- confusion matrix와 IoU 기준별 AP는 v3 e20 하나로만 봤다
