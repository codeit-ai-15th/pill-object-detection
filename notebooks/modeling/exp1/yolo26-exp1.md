# YOLO26s 1차 실험 (원본 232장)

- 담당: 이채영
- 노트북: [`yolo26-exp1.ipynb`](yolo26-exp1.ipynb)
- 결과 파일: 드라이브 `pill data/runs/` (run 폴더별 `results.csv`, 제출 csv, `weights/`), `pill data/runs/figures/`

## 목적

EDA에서 클래스 불균형이 크고, test에는 있지만 train에는 없는 약이 18종 있다는 걸 확인했다. 원본 데이터만으로 어디까지 되는지 기준 성능을 잡고, 부족하면 원인을 찾는 게 목표.

## 데이터와 설정

| 항목 | 값 |
| --- | --- |
| 데이터 | 원본 232장 (train 185 / val 47), 56클래스, 박스 771개 (train 612 / val 159), 라벨 수정 반영 |
| 분할 | 약 조합 단위, seed 410. val 조합 25개 중 train에 있는 조합 0개. 희귀한 약은 train 고정 |
| 클래스 불균형 (train) | 최소 3 / 최대 128박스 (42.7배), 3박스뿐인 클래스 21개 |
| 모델 | yolo26s, COCO 사전학습에서 전체 fine-tuning (파라미터 948만 개, 20.9 GFLOPs) |
| 학습 | imgsz 640, batch 16, 100에폭, patience 30, optimizer auto → AdamW lr 0.000167 |
| 환경 | Colab T4, ultralytics 8.4.183 |

## 결과

| 실험 | best val mAP50-95 | Kaggle public |
| --- | --- | --- |
| 기준 (100에폭, seed 0) | 0.976 | 0.410 |
| seed 1 | 0.962 | 0.410 |
| seed 2 | 0.956 | 0.390 |
| 상하 뒤집기 0.5 | 0.968 | 0.403 |
| 해상도 1280 (batch 8) | 0.966 | 0.403 |
| 20에폭 | 0.858 | 0.325 |
| 30에폭 | 0.949 | 0.380 |
| 50에폭 | 0.974 | 0.404 |
| 라벨 수정 전 | 0.974 | 0.392 |

- val mAP50-95는 ultralytics가 학습 중에 잰 값 (IoU 0.5~0.95)
- seed만 바꿔도 Kaggle이 0.390~0.410 움직여서, 0.02보다 작은 차이는 차이로 안 봄
- 기준 run을 대회 지표 mAP@[0.75:0.95]로 val 47장에 재면 0.9615

## 분석

- **박스는 찾고 약 종류를 틀린다.** val 159개 중 149개 맞춤(conf 0.25, 직접 셈). 클래스 틀림 6개는 전부 20238이고, 박스 IoU는 0.97~0.99로 위치는 정확했다. 못 찾음 4개(30308 3개, 25469 1개)
- **클래스별 AP(대회 지표)**: 30종 중 19종이 1.0. 가장 낮은 건 30308(0.617, train 3박스), 20238(0.877)
- **과적합 아님**: train/val loss가 끝까지 같이 내려갔고, 100에폭(0.410)이 50에폭(0.404)보다 안 떨어짐
- **test 예측**: train 3박스뿐인 희귀 약이 기대보다 최대 8.9배 많이 예측됨(과잉 예측 상위 10개 중 7개). 같은 알약에 다른 약 박스가 겹친 사진 38장
- ultralytics가 그려주는 confusion matrix는 mAP와 안 맞아서 쓰지 않음

## 결론

- val과 Kaggle 차이는 과적합, 분할 누수, 평가 지표 차이가 아니다
- 남는 원인은 test에 있는 모르는 약. 모르는 약을 생김새가 비슷한 희귀 약으로 몰아 찍는 걸로 보인다
- 증강·해상도·에폭은 시드 흔들림(0.02) 안이었다. 모르는 약은 데이터로만 해결되니 외부 데이터(AI Hub)를 보충하기로 함

## 한계
